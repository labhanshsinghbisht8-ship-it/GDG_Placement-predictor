# GDG_Placement-predictor


## Objective
Built a binary classification model using GDG placement dataset to predict whether a student is ready for placement.

## Tech Stack
- Python, Pandas, NumPy, Scikit-learn

## Pipeline
1. Data Cleaning & Label Encoding for categorical values.
2. Model Training: Logistic Regression & Decision Tree.
3. Evaluation using Precision, Recall, and F1-Score.
